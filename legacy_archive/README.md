# Legacy Firebase Architecture Archive

This directory archives the original Firebase Realtime Database implementation of MYVT.
It preserves the original scripts, configs, and historical data export for reference and backup.

## Contents
- `style.css`: Original monolithic CSS before splitting into `asset/css/{core,layout,themes}.css`.
- `firebase_backup.json`: Complete JSON database export from Firebase Realtime Database.
- `script.js`: Original monolithic imageboard script.
- `backup-script.js`: Historical backup script.
- `titpfetmm.js`: Original obfuscated admin module.
- `asset_js_config.js`: Original Firebase configuration and board setup.
- `asset_js_app.js`: Original Firebase client-side routing & rendering logic.
- `asset_js_admin.js`: Obsolete client-side password script.
